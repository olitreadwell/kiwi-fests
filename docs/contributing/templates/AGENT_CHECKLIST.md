# Agent checklist

Run through this before finishing any task.

## Before writing code

- [ ] Read `AGENTS.md` and `docs/contributing/00-index.md`
- [ ] Found the relevant code and tests by searching, not guessing
- [ ] Noted any project rules that override the generic guide

## During

- [ ] Change stays inside the requested scope
- [ ] Tests added or updated alongside behavior
- [ ] No fabricated data, stats, or "it works" claims
- [ ] Naming and style match the surrounding code

## After

- [ ] Ran the repo's checks (lint, format, typecheck, tests, build)
- [ ] Re-ran targeted tests after the last edit
- [ ] Summary states what changed, what ran, and what is unverified

## Never

- [ ] No secrets committed
- [ ] No unrelated refactors
- [ ] No claimed verification without a run
